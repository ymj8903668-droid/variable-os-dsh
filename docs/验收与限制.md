## 反馈优先级

优先反馈阻断真实使用的问题：无法安装、认证地址无法打开、自己的授权连接失败、同一原卡版本错误、撤权后仍可联网读取、私人数据串用。请附系统版本、发布标签、错误码及脱敏步骤。

不要上传访问令牌、含认证参数的本地 URL、原始研究资料、数据库或整个 HOME。高风险安全问题不要在公开 Issue 中附可利用细节。
