# 源码构建与二次开发

本仓库的 `plugin-source/` 是 0.1.1 插件的对应源码闭包，包含中文界面、Host 适配、HTTP/SSE 消费、七个 stdio MCP 工具、构建器和固定依赖锁。不包含网站完整后台、私人研究引擎、资料库或主开发库全量测试。

## 精确重建发布插件

需要 Node **24.19.0**、pnpm **11.25.0**。建议使用独立账户或独立 HOME，不读取已有生产配置。

```sh
git clone https://github.com/ymj8903668-droid/variable-os-dsh.git
cd variable-os-dsh
git checkout v0.1.1-preview.20261019
cd plugin-source
pnpm --dir scripts/plugin-source-build-deps install --frozen-lockfile --ignore-scripts
```

新建一个空的私有输出目录（权限 700），并替换下面的绝对路径：

```sh
mkdir -m 700 /absolute/new/plugin-output
node scripts/rebuild-plugin-source.mjs --output /absolute/new/plugin-output
```

正确结果为 `SOURCE_REBUILD_VERIFIED`，输出 32 个已核验文件，清单 SHA-256：

```text
79a437cde230423dd663cb714c1bad093ca4e627e0d5270e433cb5e21d13657c
```

此过程检查原源码哈希、重建并逐项对照预期插件清单；不会安装 DSH、启动服务或调用模型。依赖下载需联网，源码重建无需服务凭证。

## 修改自己的版本

在新分支或副本编辑 `plugin-source/packages/dsh-desk-ui/src/` 等模块。原样重建校验器会拒绝修改后的源文件，这是正常的身份校验。不要改预期哈希来冒充官方产物。修改版使用原有构建器：

```sh
cd plugin-source
node packages/dsh-desk-ui/scripts/build-client.mjs
mkdir -m 700 /absolute/new/my-plugin-output
node scripts/build-dsh-plugin.mjs --output /absolute/new/my-plugin-output
```

给修改版使用清晰的新版本和自己的发布说明；以新生成的包清单记录实际内容。在独立 DSH profile 验证后再自行打包。不要将预览安装器的冻结校验改成跳过校验来安装不匹配包。

`plugin-source/docs/BUILD_AND_TEST.md` 记录的是原完整开发库流程，里面未随此闭包提供的测试和运维入口不能在此仓库直接运行。对应源码的入口说明是 [PLUGIN_SOURCE_BUILD.md](../plugin-source/docs/PLUGIN_SOURCE_BUILD.md)。
