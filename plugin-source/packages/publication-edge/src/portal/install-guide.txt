# 变量发现台：私有候选安装与接入

本包尚未公开发布。下载成功不代表安装成功、跨平台兼容或生产验收。
请在专用测试账户和隔离工作区中使用，仅接入运营方明确批准的测试服务或公开服务；
不要导入业主未批准发布的研究资料、私有凭证或旧安装状态。

## 安装前

远程 MCP 接入（2026-10-15 源码候选新增）
登录账户网站，在「接入说明」下载「远程 MCP 接入信息」。在原中文插件的
「信源连接」导入此 JSON，再填写自己的读取令牌，保存并检查连接。
也可在 API 服务地址填写同一后台的 /mcp 地址；插件自动使用同站 HTTP/SSE
同步完整业主原卡，无需模型 Key，不会重新生成业主的卡。
下载文件不含令牌；本地 stdio MCP 仍可由插件导出，并共用已保存授权。
通用远程 MCP 客户端需支持 Streamable HTTP 和自定义 Authorization Bearer
请求头；仅支持 OAuth 的客户端尚未验收。公网 HTTP 只读入口没有这些能力。
请核对安装候选的回执；历史包不因说明更新而自动包含这些修复。

主入口是已有兼容官方 DSH 中的 TGZ 插件安装，不需要另装一套变量发现台客户端。
插件复用 Host 的 SDK 与模型运行库；启用前检查精确版本和原生能力。
若出现 PUBLIC_PLUGIN_RUNTIME_INCOMPATIBLE，请保留错误并核对兼容环境，
不手工修改 SDK 版本信息或改用 latest 绕过检查。
Windows、Linux 普通桌面的实际插件使用仍未验收；已有 Linux arm64 容器证据
不能代替桌面或其他平台验收。每份候选须对应自己的归档与验收回执。

账户页显示的版本、文件大小及 SHA-256 对应运营方指定的私有候选。
请从同一可信账户页下载插件与本说明；来源不明或校验失败的包不要安装。
插件内 build-manifest.json 列出文件摘要；ZIP 另含 installer-manifest.json。
运营方固定的摘要仅证明文件一致性，不代替源码、资产授权和发布审阅。

## TGZ 官方插件入口

TGZ 需要已有的官方 DSH 0.2.1-alpha.2、Node 24 和 pnpm 11.25.0，
兼容 SDK 为 0.2.1-alpha.2、pi-ai 为 1.1.0。请先在同一终端核对版本。

    node --version
    pnpm --version
    dsh --version

官方 Host 安装资料（固定本候选对应版本）：
https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.2/README.md
官方 CLI 的 profile 与插件管理说明：
https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.2/apps/cli/README.md

尚未准备好兼容 Host 时，先按官方资料准备并核对版本，再回到本说明。
官方文档中的通用启动示例不保证选中本候选的精确版本；不要用无版本命令
临时下载最新 Host 来替代已有兼容环境。安装官方 Host 不会自动修复其全部依赖，
也不等于本插件已具备全平台或完整安全验收。

当前已核实的是官方 DSH 自带的命令行插件管理入口，尚无经过验收的一键安装链接。
账户页提供 TGZ 时，在隔离环境中使用已经存在的 dsh 命令安装刚下载的本地文件：

    dsh plugin --profile web add "/absolute/path/to/variable-os-dsh-0.1.1.tgz"

引号中的路径应是本次下载的实际文件，版本应与账户页一致。
TGZ 内没有生命周期安装脚本或独立运行时，使用 Host 已有的原生 HMR 与依赖。
直接安装 TGZ 不会给外部 Host 应用 ZIP 独立工具链的依赖修复；
其依赖与安全状态须单独核对。请先确认运行环境和网络策略。
安装命令成功结束后，在同一测试账户、同一 DSH_HOME 和拟使用的隔离工作目录中，
手动启动刚安装插件的 web profile：

    dsh --profile web

这是本候选使用的官方 CLI profile 启动命令。
打开终端显示的本地地址，进入原中文「变量发现台」；保留启动终端，用 Ctrl+C 停止。
这一步只启动 Host 和界面，不提交模型任务；连接数据、成卡、研究和语音仍需另行显式操作。
本节仅用于 TGZ 的 web profile；ZIP 安装仍使用 Start.command，不混用安装位置或个人状态。
若权限、SDK 或原生能力不满足，保留错误并停止，不修改个人状态目录权限强行启用。

## macOS ZIP 安装候选（独立辅助入口）

此路径需要 Node 24；在确认安装后，于 ~/.variable-os-plugin/tools 准备独立的
官方 DSH 0.2.1-alpha.2 与 pnpm 11.25.0，使用随包冻结依赖和限定的 Office ZIP
解析依赖修复，禁用依赖安装脚本。它不修改全局工具或已有 DSH，也不自动安装 Node。

账户页提供“下载 macOS 安装包”时，下载的是 ZIP，不要交给 dsh plugin add。
解压后保留整个文件夹，打开 Install.command，按系统正常安全确认流程操作。
不要移除隔离标记或关闭安全检查；此候选尚无签名、公证和 Finder 打开验收。
确认提示输入 y 才进行一次安装，其他输入或关闭输入均取消。
入口使用独立的 ~/.variable-os-plugin/installation，不覆盖已有或失败的安装。
首次确认包含联网下载独立工具链；下载或校验失败时停止并保留错误，不自动重试。
已存在的安装不会被覆盖；旧工具链不符合当前候选时也不会被静默更新。
安装和导入校验成功后，再次输入 y 可启动 Host 并打开原中文配置页；
拒绝或关闭这次确认只保留安装，不启动 Host。
以后打开同一文件夹内的 Start.command，沿用该安装的个人状态。
保留启动窗口，用 Stop.command 或关闭窗口停止；重新启动不重复安装。
启动只核对已有独立工具链，不下载、安装或回退到全局工具。
启动不自动启用信源、模型或语音。真实系统打开、安全确认及完整发行仍待验收，
不能把脚本子进程验收等同于 Finder 双击或完整的一键启用流程。

## 信源与可选服务

主线是业主生产、确认并发布卡片，再授权消费者在原中文插件中同步同一张完整原卡。
消费者只需信源接入信息和访问令牌，无需模型 Key，也不会重新生成业主的卡。
在原插件统一配置页添加发布卡信源，保留上游 ID、版本、发布哈希和证据引用。
自动更新使用 HTTP/SSE；修订替换原版本，撤回和撤权清理相应数据。
API 地址、证书指纹、必要的自签证书来自账户页「下载接入信息」；
公开受信证书可使用 Node 默认信任库，无需另下载 CA 文件；私有测试证书仍需明确配置。
直接使用 stdio 环境变量时可省略 VARIABLE_OS_EDGE_CA_FILE；填写了无效文件会拒绝连接。
两种方式都保留证书链、域名、TLS 1.3 和指纹检查，不要关闭证书验证。
个人访问令牌单独填入原插件的 Host 设置，不会包含在接入信息或插件包中。
不要把令牌写进 URL、日志、截图或聊天消息。
七个只读 stdio MCP 工具与原插件共用同一信源授权，不接受写工具。

个人 IMA/API 成卡、自己的模型深搜和豆包语音都是可选功能。
仅在需要时填写自己的相应服务凭证；未配置不影响授权发布卡的同步查看。
网站普通 AI 与付费深研的目标是平台供给，普通网站用户不自配模型 Key；
本机个人研究配置仍属可选功能。是否上线以运营方当前功能状态为准。
截至 2026-10-17，正式域名已验证注册、邮件与登录；公共库为空，平台 AI 未启用。
完整原卡公网链、独立用户与研究质量仍未验收；真实豆包暂缓，Windows 停验。
保存不等于启用：连接检查、接收信源、成卡、深度研究和语音都需要对应的显式操作。
付费模型调用、外部网络访问和麦克风不是安装或保存配置时自动启动的。
切换信源后先确认旧任务已经取消；个人研究留在本机。

## 重启、升级与退出

先在隔离环境完成配置、同步完整发布卡、修订、重启回读、撤回与撤权清理。
只检查自己启用的可选服务；未测试的服务记为未验收，不以界面正常代替。
本候选尚未提供经过验收的一键升级、卸载清理或跨版本数据回退流程。
不要覆盖已有工作环境，也不要删除官方 DSH 的个人数据来“重装”。
需要停止数据访问时，先停用插件连接，再在账户页撤销对应凭证。
退出网页只结束网页会话，不会撤销已经发放给插件的个人数据凭证。
